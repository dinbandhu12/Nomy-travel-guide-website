# Nomy - Travel Guide Website

Welcome to the **Nomy** frontend project! This is modern, smart travel planner and guide built with Next.js and Tailwind CSS. It features premium designs, glassmorphism UI layouts, and beautiful scrolling animations powered by GSAP.

## Getting Started

First, make sure to install all the dependencies:

```bash
npm install
# or
yarn install
# or
pnpm install
```

Start the development server:

```bash
npm run dev
# or
yarn dev
# or
pnpm dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.

## Tech Stack

- **Next.js**: React framework for the web
- **Tailwind CSS**: Utility-first CSS framework for styling
- **GSAP**: For high-performance parallax scrolling and reveal animations
- **Lucide React**: Beautiful pre-designed icons
- **Lenis**: Smooth scrolling engine

## Project Structure
- `components/`: Reusable React components (like `home-page.tsx`)
- `lib/`: Standard utilities, GSAP setup, and static data arrays
- `public/`: Assets like images, icons, and branding elements

## Features
- **Smart Itineraries & Budget Clarity**: Visual feature cards
- **Parallax Animations**: Dynamic hero imagery that moves smoothly as you scroll
- **Glassmorphism Design**: High-fidelity layered translucent designs

## Building for Production

To create an optimized production build, run:

```bash
npm run build
npm run start
```
